### Dynamic Cost-Sensitive WGAN-GP with Stackelberg Game Theory for Robust Network Intrusion Detection
*Python, PyTorch, scikit-learn, UNSW-NB15 | Game Theory elective project, SVNIT | In progress*

A study of class imbalance and train-to-test distribution shift in network intrusion detection, developed with two teammates. The source code is not publicly available.

- Built Random Forest, Logistic Regression and MLP baselines (Random Forest: 89.3% accuracy, ROC-AUC 0.981).
- Implemented static, dynamic, threshold-tuned and feedback-based cost-sensitive learning, compared in a 5-seed paired study.
- Designed a diagnostic that separates class scarcity, train-to-test shift and class overlap to decide which attack classes benefit from synthetic data.
- Trained a WGAN-GP, with a cost-aware sampling variant and selective log-scaled features, to generate protocol-valid, integer-constrained flows for rare attacks such as Shellcode (under 0.6% of traffic).
- Formulated the defender-attacker interaction as a Stackelberg game in which the defender commits to a detector and the attacker best-responds by choosing the attack category with the highest expected payoff.
